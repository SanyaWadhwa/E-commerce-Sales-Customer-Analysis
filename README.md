# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project analyzes the Brazilian E-Commerce Public Dataset by Olist using MySQL to uncover business insights across sales, customers, products, sellers and payment behavior.

The analysis uses multiple relational tables and SQL techniques to transform raw e-commerce data into meaningful business insights.

---

## 🎯 Business Objectives

The project focuses on:

- Analyzing overall sales performance
- Identifying monthly revenue trends
- Finding top-performing products and categories
- Understanding customer purchasing behavior
- Identifying one-time and repeat customers
- Evaluating seller performance
- Analyzing payment behavior
- Measuring revenue contribution by product category

---

## 🗂️ Dataset

Source: Brazilian E-Commerce Public Dataset by Olist

The dataset contains information about orders, customers, products, sellers, payments and other e-commerce activities.

### Dataset Size Used

| Table | Records |
|---|---:|
